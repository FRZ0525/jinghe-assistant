# 晶核助手

用于记录《晶核》常规服和赛季服的副本次数和每日体力。首次打开显示常规服。每个账号可管理多个区服及其角色。

账号、区服、角色和进度保存在访问当前网址的浏览器本地存储。旧版角色会自动迁移到「默认区」，可以在角色菜单里移到实际区服。换设备或网址时，可以通过页面的「数据备份」导出和导入 JSON。

账号可折叠并显示待办数。支持从顶部跳转待办、调整剩余次数、批量记录和撤销。各服分别记住列表设置。

在「设置」中管理副本目录、选择多选或双副本轮换，并调整次数上限。两服分别保存配置。

GitHub Pages 的发布源为 main 分支根目录。网页、脚本、样式和图片可以直接放到静态网站服务器的同一目录。
